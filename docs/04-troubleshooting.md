# 트러블슈팅

겪은 문제와 해결법을 증상별로 모은다.

## 업로드가 안 됨

```
Connecting......................................
A fatal error occurred: Failed to connect to ESP32: No serial data received.
```

순서대로 확인한다.

1. **배선 합선 확인**: 실제 원인은 GND 점퍼가 엉뚱한 줄에 꽂힌 것이었다. 브레드보드에서 점퍼를 빼거나 보드만 단독으로 연결해서 업로드해 본다.
   - EN 줄에 GND가 붙으면 ESP32가 계속 리셋 상태로 멈춘다.
   - VIN 줄에 GND가 붙으면 5V가 합선된다. 가장 위험하다.
2. **BOOT 버튼**: `Connecting...`이 뜨면 BOOT 버튼을 누르고 있다가 `Writing at ...`이 나오면 뗀다. 끝나면 EN 버튼으로 재시작.
3. 시리얼 모니터 닫기 (COM 포트를 붙잡고 있을 수 있음)
4. 툴 → Upload Speed를 115200으로
5. 툴 → 보드가 "ESP32 Dev Module"인지
6. 데이터 전송이 되는 USB 케이블인지 (충전 전용 케이블 X)

업로드 성공 시 출력 마지막에 `Hard resetting via RTS pin...`이 뜬다.

## LED가 안 켜짐

- LED 짧은 다리가 + 레일에 꽂혀 있지 않은지 → − 레일로
- − 레일이 ESP32 GND와 점퍼로 이어져 있는지
- LED 방향 (긴 다리가 저항 쪽)
- 저항이 가운데 홈을 건넜는지. 양쪽 다리가 같은 쪽(a~e)이면 저항이 건너뛰어진다.
- LED만 깜빡이는 코드로 따로 테스트해서 원인을 좁힌다.

## 버튼이 반응하지 않음

시리얼 모니터에 `digitalRead` 값을 찍어 본다.

| 증상 | 원인 |
| --- | --- |
| 1만 찍히고 눌러도 안 바뀜 | 버튼 배선. 버튼 방향(90도 돌리기)이나 D27 점퍼 줄 확인 |
| 0/1은 바뀌는데 LED가 안 켜짐 | LED 쪽 배선 |
| 아무것도 안 찍힘 | 업로드가 안 됨, 또는 시리얼 속도 불일치 |

## LED가 켜졌다 바로 꺼짐

- `setup()`에서 켜도 `loop()`에서 다른 값을 쓰고 있지 않은지
- `==` 대신 `=`을 쓰지 않았는지
- 인터럽트 버튼이면 바운싱 → [디바운싱](03-concepts.md#바운싱과-디바운싱)
