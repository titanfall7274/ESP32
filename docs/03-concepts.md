# 개념 정리

실습하면서 만난 개념을 모아 둔다. 새로 배울 때마다 추가한다.

## GPIO

| 이름 | 설명 |
| --- | --- |
| `pinMode(핀, 모드)` | 핀을 `OUTPUT`, `INPUT`, `INPUT_PULLUP` 중 하나로 설정 |
| `digitalWrite(핀, 값)` | 출력 핀에 HIGH/LOW를 씀. 블로킹 아님. 핀은 한 번 쓴 값을 계속 유지함 |
| `digitalRead(핀)` | 입력 핀 값을 읽음. 블로킹 아님 |

LED를 계속 켜두려면 `setup()`에서 `digitalWrite(LED, HIGH)` 한 번이면 된다. 다만 `loop()`에서 다른 값을 쓰면 바로 덮어쓴다.

## 시간

| 이름 | 설명 |
| --- | --- |
| `delay(ms)` | 블로킹. 그동안 이 task는 다른 일을 못 함 |
| `millis()` | 부팅 후 지난 시간(ms). `unsigned long`에 담음. 약 49일 뒤 0으로 돌아가지만 `now - last` 빼기 비교는 그때도 맞게 계산됨 |

`delay` 없이 주기적으로 일하는 패턴:

```cpp
unsigned long last = 0;
bool on = false;

void loop() {
  if (millis() - last >= 500) {
    last = millis();
    on = !on;
    digitalWrite(26, on);
  }
  // 여기서 다른 일을 계속 할 수 있음
}
```

ESP32 아두이노의 `loop()`는 FreeRTOS task 하나로 돈다. `delay()`는 그 task만 재우고 CPU는 다른 task에 넘겨준다.

## 폴링과 인터럽트

- **폴링**: `loop()`가 "버튼 눌렸어?"를 계속 물어보는 방식
- **인터럽트**: 버튼이 눌린 순간 하드웨어가 CPU를 불러서 정해둔 함수를 실행하는 방식
- **ISR (인터럽트 서비스 루틴)**: 인터럽트로 불리는 함수

| 이름 | 설명 |
| --- | --- |
| `attachInterrupt(digitalPinToInterrupt(핀), 함수, 조건)` | 이 핀에서 이 조건이 생기면 이 함수를 부르도록 등록 |
| `FALLING` | 1 → 0 순간. 풀업 버튼에서는 누르는 순간 |
| `RISING` | 0 → 1 순간. 풀업 버튼에서는 떼는 순간 |
| `IRAM_ATTR` | ISR을 플래시가 아니라 RAM에 올림. 플래시에 쓰는 동안 인터럽트가 와도 죽지 않게 |
| `volatile` | 매번 메모리에서 다시 읽으라는 표시. ISR과 `loop()`가 같이 쓰는 변수에 붙임 |

ISR 규칙:

- 짧게 끝낸다. 깃발(flag)만 세우고 실제 처리는 `loop()`에서 한다.
- ISR 안에서 `Serial.println`, `delay`를 쓰지 않는다.

## 바운싱과 디바운싱

- **바운싱**: 버튼 접점이 닿거나 떨어질 때 몇 ms 동안 미세하게 튀면서 0과 1을 빠르게 반복하는 현상. 누를 때와 뗄 때 둘 다 생긴다.
- 인터럽트는 이 짧은 변화를 전부 잡기 때문에, 한 번 눌러도 토글이 여러 번 일어나 결과가 랜덤처럼 보인다.

디바운싱 2단계:

1. **ISR에서 시간 필터**: 마지막으로 인정한 시각에서 200ms 안에 들어온 인터럽트는 무시한다.
2. **`loop()`에서 재확인**: 20ms 기다린 뒤 버튼이 아직 눌려 있을 때만 인정한다. 손을 뗄 때 튀어서 생긴 FALLING은 이때 이미 1이라 걸러진다.

시간 필터만 쓰면, 200ms 넘게 누르고 있다가 뗄 때 튄 신호가 새 누름으로 인정돼 LED가 꺼진다. 시간을 줄이면 오히려 더 자주 생긴다.

## 시리얼 출력 (UART)

| 이름 | 설명 |
| --- | --- |
| `Serial.begin(115200)` | 시리얼 시작. 시리얼 모니터 속도도 115200으로 맞춤 |
| `Serial.print` / `println` | 출력 / 출력 + 줄바꿈 |
| `Serial.printf("누름 %d번\n", n)` | C printf 형식. 여러 값을 한 번에 출력 |

`Serial.println(a, b)`의 두 번째 인자는 출력 형식(진법)이다. `println(5, BIN)` → `101`. 값을 이어 붙이는 용도가 아니다.

## C 실수 모음

- `=`는 대입, `==`는 비교. `b = LOW ? HIGH : LOW`는 매번 LOW를 대입한다. `LOW == b`처럼 상수를 왼쪽에 쓰면 실수를 컴파일러가 잡아준다.
- 대소문자 구분: `lastTime`과 `lasttime`은 다른 변수다.
- 변수는 쓰기 전에 선언: `unsigned long now = millis();`

## 앞으로 볼 개념 (한 줄 정리)

- **예외 처리**: 0으로 나누기, 잘못된 주소 접근 등을 CPU가 만나면 멈추고 처리 루틴으로 감. ESP32의 "Guru Meditation Error"
- **DMA**: CPU 대신 전용 하드웨어가 데이터를 옮겨 줌
- **메모리 정렬**: 4바이트 데이터는 4의 배수 주소에 둠
- **엔디언**: 여러 바이트의 저장 순서. ESP32는 리틀 엔디언
- **저전력 모드**: 안 쓸 때 CPU를 재움. deep sleep
- **RTOS**: 작은 기기용 OS. 여러 task를 정해진 시간 안에 번갈아 실행. ESP32는 FreeRTOS
