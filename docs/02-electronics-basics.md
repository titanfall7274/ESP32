# 전기 기초

시작하는 데는 중학교 과학 수준의 옴의 법칙과 ESP32 주의사항 몇 개면 충분하다. 나머지는 부품을 붙이면서 필요할 때 배운다.

> 지킬 것 세 가지: 5V 넣지 않기, LED에는 저항 달기, GND 공통 연결하기

## 꼭 알아야 할 것

- **3.3V 로직**: ESP32 GPIO는 3.3V다. 5V 센서나 모듈을 GPIO에 바로 연결하면 칩이 상할 수 있다.
- **핀당 전류 한계**: GPIO는 LED 정도만 직접 구동한다. 모터나 릴레이는 트랜지스터나 드라이버 모듈을 거친다.
- **옴의 법칙 V = I × R**: LED 저항 계산에 쓴다.
  - (3.3V − LED 약 2V) ÷ 10mA ≈ 130Ω → 여유 있게 220Ω 사용
- **LED 극성**: 긴 다리(+)는 저항 쪽, 짧은 다리(−)는 GND 쪽. 반대로 꽂으면 안 켜질 뿐 고장은 나지 않는다.
- **풀업 저항**: 버튼을 안 눌렀을 때 핀 값이 0인지 1인지 떠다니지 않게 1로 잡아준다. ESP32 내장 풀업(`INPUT_PULLUP`)을 쓰면 평소 1, 누르면 0이다.
- **GND 공통**: 외부 부품과 ESP32의 GND를 꼭 이어야 회로가 닫힌다.

## 저항

방향이 없다. 값은 몸통의 색 띠로 읽는데, 파란 몸통(금속 피막) 저항은 띠가 5개다. 간격이 넓은 띠를 오른쪽에 두고 왼쪽부터 읽는다.

| 값 | 색 띠 | LED에 쓰면 |
| --- | --- | --- |
| 10Ω | 갈색 검정 검정 금색 갈색 | 안 됨. 전류가 너무 많이 흐름 |
| 220Ω | 빨강 빨강 검정 검정 갈색 | 적당함 |
| 1kΩ | 갈색 검정 검정 갈색 갈색 | 조금 어둡지만 안전함 |
| 10kΩ | 갈색 검정 검정 빨강 갈색 | 너무 어두움 |

헷갈리면 멀티미터 Ω 모드로 재는 게 가장 확실하다.

## 4다리 택트 스위치

- 다리 2개씩 안에서 이미 연결된 2쌍 구조다. 누르면 두 쌍이 서로 이어진다.
- 브레드보드 가운데 홈에 걸쳐 꽂는다. 홈을 사이에 두고 마주 보는 두 다리가 원래 붙어 있는 쌍이다.
- 항상 눌린 것처럼 동작하면 90도 돌려서 다시 꽂는다.
- 대각선 다리 2개만 쓰면 방향과 상관없이 동작한다.
- 멀티미터 통전(삐) 모드로 안 눌렀는데 삐 소리 나는 두 다리가 원래 붙은 쌍이다.
