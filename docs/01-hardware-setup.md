# 하드웨어 세팅

ESP32 30핀 보드는 폭이 넓어서 브레드보드 하나에 꽂으면 한쪽 핀을 쓸 수 없다. 그래서 830 보드의 전원 레일 한 줄을 떼고 400 보드와 나란히 붙여 ESP32를 두 보드에 걸쳐 꽂았다.

## 보드 배치

- USB를 위로 두고 꽂았다.
- 오른쪽 핀 열(VIN, GND, D13, D12, D14, D27, D26, D25, D33, D32, D35, D34, VN, VP, EN)은 400 보드 쪽에 온다.
- 왼쪽 핀 열(3V3, GND, D15, D2, D4, RX2, TX2, D5, D18, D19, D21, RX0, TX0, D22, D23)은 830 보드 쪽에 온다.
- 400 보드 안쪽 레일은 ESP32 밑에 깔려서 못 쓰고, 바깥쪽 레일(빨강 +, 파랑 −)을 쓴다.
- 핀 이름은 항상 보드에 인쇄된 글자로 확인한다. 같은 30핀이라도 제품마다 배열이 다를 수 있다.

## 브레드보드 연결 규칙

- 한 줄의 a~e 5칸은 안에서 연결돼 있다. f~j 5칸도 따로 연결돼 있다.
- 가운데 홈을 넘어서는 연결되지 않는다.
- ESP32 핀이 꽂힌 줄의 빈칸에 점퍼를 꽂으면 그 핀에 연결한 것과 같다.
- 빨강(+)·파랑(−) 레일은 세로 한 줄 전체가 연결돼 있다. 830 보드 중에는 레일이 가운데에서 끊긴 제품도 있다.
- 레일은 저절로 전원이 되지 않는다. − 레일은 ESP32 GND 핀에 점퍼로 이어야 GND가 된다.

## 첫 회로: LED + 버튼

| 연결 | 위치 |
| --- | --- |
| GND 점퍼 | ESP32 GND 줄 (VIN 바로 아래) e칸 → − 레일 |
| 220Ω 저항 | D26 줄 e칸 → 홈 건너 같은 줄 g칸 |
| LED 긴 다리(+) | D26 줄 j칸 |
| LED 짧은 다리(−) | − 레일 |
| D27 점퍼 | D27 줄 d칸 → 버튼이 있는 줄 |
| 버튼 | 가운데 홈에 걸쳐 꽂음. 한쪽은 D27 점퍼 줄, 홈 건너편은 − 레일로 |

전류 흐름: D26 → 저항 → LED → − 레일 → ESP32 GND

```
D26 ─ 220Ω ─ LED 긴 다리(+) ─ LED 짧은 다리(−) ─ − 레일 ─ ESP32 GND
D27 ─ 버튼 ─ − 레일 ─ ESP32 GND   (평소 내장 풀업으로 1, 누르면 0)
```
