## 겪은 문제

| 문제 | 원인 | 해결 |
| --- | --- | --- |
| 업로드 실패 (No serial data received) | GND 점퍼가 GND가 아닌 옆 줄(EN 또는 VIN)에 꽂힘 | 점퍼를 빼니 바로 정상 동작. GND 줄 확인 후 다시 꽂음 |
| LED가 안 켜짐 | LED 짧은 다리와 버튼 쪽 선이 + 레일에 꽂힘 | − 레일로 옮김 |
| 컴파일 에러 | `Serial.pirntln` 오타 | `println` |
| LED가 항상 꺼짐 | `b = LOW ? HIGH : LOW` (대입) | `b == LOW` (비교) |
| 한 번 눌러도 토글이 랜덤 | 바운싱. 인터럽트가 여러 번 들어와 짝수 번이면 원래대로 | ISR에서 200ms 시간 필터 |
| 오래 누르다 떼면 꺼짐 | 뗄 때 튀어서 생긴 FALLING이 200ms 이후라 새 누름으로 인정됨 | `loop()`에서 20ms 뒤 `digitalRead`로 재확인 |

## 관찰

- 버튼 1번 누를 때 인터럽트는 보통 1번이지만 가끔 여러 번 들어온다 (누름 45번 / 인터럽트 46번).
- `pressed`가 `bool`이라 `loop()`가 확인하기 전에 들어온 여러 인터럽트는 하나로 합쳐진다. 그래서 `실제 누름 ≤ loop 처리 횟수 ≤ 인터럽트 횟수`.
- 디바운싱 시간은 짧을수록 좋은 게 아니다. 시간만으로는 뗄 때의 바운싱을 못 잡는다.

## 배운 것

- 브레드보드 연결 규칙, 레일은 GND에 이어야 GND가 된다
- 옴의 법칙으로 LED 저항 계산, 저항 색 띠 읽기
- `digitalWrite`/`digitalRead`는 블로킹이 아니고 `delay`는 블로킹
- `attachInterrupt`, `FALLING`, `IRAM_ATTR`, `volatile`
- ISR은 짧게: 깃발만 세우고 처리는 `loop()`에서
- `Serial.printf`
